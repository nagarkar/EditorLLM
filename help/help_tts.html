TTS Screen
The TTS screen is for voice selection, narration generation, directive-based generation, and pronunciation dictionary management.
  • Generate Audio reads the selected tab with the chosen voice and model.
  • Generate Audio (HQ) saves a higher bitrate MP3 intended for production-ready review.
  • Generate from Directives uses tab-level TTS directives instead of a single static voice.
  • Saved audio filenames include the source tab name so version-folder audits can match expected narration outputs.
  • Pronunciation Dictionaries and the directive editor are separate overlays available from the TTS workflow.
