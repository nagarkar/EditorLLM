Overlays
Several workflows open as overlays instead of changing screens.
  • Sweep Tabs lets you choose which tabs an annotation agent should process.
  • Generate All Publishing Tabs asks for confirmation before overwriting the current publisher tabs.
  • Last Audit Results shows the latest EPUB and Audio readiness report returned by the Publisher structural audit.
  • Pronunciation Dictionaries and Directive Editor support TTS refinement without leaving the current screen.
  • Help is itself an overlay with anchor links so you can stay in context while navigating documentation.
