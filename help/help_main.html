Main Screen
The Main screen is the editing control surface for Architect, Ear-Tune, Audit, Tether, tab merging, and shared setup.
  • Model Configuration sets provider, model tiers, debug mode, and annotation highlight color.
  • Structural Architect regenerates the StyleProfile used by the downstream agents.
  • Ear-Tune, Audit, and Tether can run on the active tab or across selected tabs via the sweep overlay.
  • Tab Merger defines the ordered source tabs that are merged into Manuscript; that saved list is also reused by publisher audio workflows.
  • Managed Tabs controls which tabs are eligible for destructive maintenance passes.
