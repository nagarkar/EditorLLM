Publisher Screen
The Publisher screen manages packaging tabs, versioned EPUB assets, versioned audio assets, and readiness checks.
  • Generate Instructions refreshes Publisher Instructions.
  • Generate All Publishing Tabs and Generate Missing Publishing Tabs work on Copyright, About The Author, Sales, Hooks, Cover, Opening Audio Credits, Closing Audio Credits, and Retail Audio Sample.
  • Run Structural Audit is read-only. It inspects the active version folder, EPUB assets, and expected audio files without generating new tabs.
  • Build EPUB Package writes content.docx, cover.png, and style_inkfluence.css into the versioned EPUB folder.
  • Build ACX Package copies the selected MP3 files into the versioned Audio folder.
